**Goal:** Pass the user's phase-0 gate: faithful content (paper ↔ blueprint), composite overview + detail figures, compact layout, richer shape vocabulary, cleaner routing — re-rendered for BLIP-2 and Restormer with before/after contact sheets.

**Architecture:** Extend the phase-0 engine (`paperfig/`): a facts file checked against the blueprint graph; new visuals (`trapezoid`, `stack`, `slab`) and operator kinds; blueprint `annotations` (overlapping brackets) and grid `place: "free"` + `detail_of` callouts; routing/lint refinements. **Spec:** `docs/superpowers/specs/2026-11-12-paper-figure-design.md` (G1 module-detail, G3 names, G5 provenance/faithfulness, §4 ⑥). User verdict and priorities: project memory `paper-figure-phase-state`, `faithfulness-gate-lesson`.

## Global Constraints
- Every rule from the phase-0 plan still holds (provenance, verbatim proposed names, no AI images for results, lint on real artifacts, provisional labels, no push).
- Measured drawio constraint transforms (2026-11-12, 9-point grids): `flipH=1`: actual = (1−ex, ey); `direction=south`: actual = (1−ey, ex); `direction=north`: actual = (ey, 1−ex). Emitter inverts, lint applies — one shared function.
- Encoder trapezoid = `shape=trapezoid;direction=south` (narrows to the right); decoder = `direction=north`.
- Operator glyphs: add ⊕, mul ⊙, matmul ⊗, concat Ⓒ, reshape Ⓡ, gelu ⊘ (all verified to render in draw.io).

## Review Focus
1. Facts that name ids missing from the blueprint, or paths that only exist through an unrelated detour → must be reported, never silently "covered" (Task 1 `test_fact_unknown_id_is_error`, `test_fact_path_must_stay_in_scope`).
2. Overlapping brackets on nodes in different rows / containers → lanes must not collide with each other, nodes or routes (Task 3 `test_brackets_overlap_in_separate_lanes`, `test_routes_avoid_brackets`).
3. Free-placed panels overlapping grid cells → LayoutError naming both (Task 4 `test_free_child_overlap_raises`).
4. Rotated/flipped shapes with ports on every side → arrows land on the drawn outline (Task 2 `test_rotated_shape_ports_roundtrip_through_lint`).
5. Operator nodes with several edges on one side → arrowheads touch the circle (Task 5 `test_op_ports_on_circle`).

### Task 1: Faithfulness facts gate
**Files:** `paperfig/facts.py`, `tests/test_facts.py`; pipeline/CLI integration (`--facts`, auto `facts.json` next to the blueprint).
`facts.json`: `{"facts": [{"id","from","to","scope"?: group-or-annotation id, "quote","ref","waive"?: reason}]}` — written from the method text/code **independently of the blueprint**. `check_facts(bp, facts) -> list[Finding]`: unknown id → error `fact-unknown-id`; no directed path from→to (through edges, stepping into/out of containers via membership) → error `fact-missing`; path exists but leaves `scope` → error `fact-out-of-scope`; waived → info. Report stats `facts_covered/total`.
