# paper-figure Phase 1 · Round 2 — reader-first, flexible figures (pilot)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (native). Checkbox steps.

**Goal:** Change the skill from "draw every stated connection in one boxes-and-containers style" to reader-first,
reference-learned figures, then pilot on Decision Transformer and TransUNet for the user's verdict.
**Spec:** `docs/superpowers/specs/2026-11-12-phase1-round2-reader-first.md` (user-approved 2026-11-12).

## Global Constraints
- All phase-0/1 constraints hold (provenance, no fabricated facts, lint on real artifacts, no push, no paid APIs).
- Omitted facts only through `figure_plan.json`; never silently.
- Example images: repo demo → public dataset sample with source + licence → image-shaped placeholder. Never generated.
- Pilot only (2 papers); rollout waits for the user's verdict.

## Review Focus
1. A fact neither drawn nor listed in `omitted` must still be an error (`test_unplanned_missing_fact_is_error`).
2. A plan concept without a reference card id is invalid (`test_plan_concept_needs_reference`).
3. Placeholder renders as an image frame at its `size`, spec not printed (`test_placeholder_is_image_frame`).
4. Legend moved into empty space must not overlap anything (`test_legend_in_empty_space_no_overlap`).
5. Short dashed edges keep a visible dash (`test_short_dashed_edge_keeps_dash`).

### Task 1: Figure plan + plan-aware facts gate
`paperfig/schema/figure_plan.schema.json`; `paperfig validate figure-plan FILE --facts F --refs R` (concept cites a card
id or a refs.json selection; core ids exist in the blueprint later; omitted ids are fact ids); `build --plan P`:
missing facts listed in `omitted` → `fact-omitted` info (reason shown), others stay `fact-missing` errors; `run check`
requires `figure_plan.json` when there is a draft. Tests: `test_plan_concept_needs_reference`,
`test_omitted_fact_is_info`, `test_unplanned_missing_fact_is_error`, `test_run_check_requires_plan`.

### Task 2: Engine fixes the pilots need
(a) placeholder = image frame (light fill, image glyph, short label) sized by `size`, spec kept out of the drawing;
(b) legend placed in the largest empty rectangle that fits (else below); (c) dashed/dash-dot edges shorter than two
periods use a shorter pattern; (d) min-font judges each run (subscript runs at 0.83, the rest at full size);
(e) the title band blocks only the title text box, so edges can enter a titled group past it; (f) `run round`
stores absolute paths. One test each; regression: restormer + blip2 rebuilds still lint-clean (pixel identity no
longer expected where (b)/(d) change output — compare visually).

### Task 3: Prompts + SKILL.md + design guide
reference-scout: rank by method-structure similarity, reject figures that redraw the paper; critic: reader test
(takeaway in one sentence, top-level unit count, clutter, distance to the chosen model card; respect `omitted`);
SKILL.md: ② references always → ③ figure plan (concepts from cards, takeaway, core ≤ 8, data visuals + image sources,
omitted with reasons) → blueprint gate shows plan + omitted; design.md: anti-"AI look" rules (no container for every
group, few tints, real data visuals, consistent stroke, follow the model card's composition).

### Task 4: Pilot
Blind runs for decision-transformer and transunet (full scout, ≤ 3 rounds); sheets *original | phase-1 | round 2* to
`~/Desktop/paper-figure-phase1-r2/`; hand to the user.
