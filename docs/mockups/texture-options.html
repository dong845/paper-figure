同一张方法图，四种质感，哪种最接近你说的「有质感」？

内容完全相同（虚构的示例方法：编码器 → 新模块 CSFM → 解码器，外加一条跳连），只有视觉处理不同。四种都能用 drawio 原生画出来，也都能继续编辑。可以多选，也可以说「A 的配色 + C 的立体感」这样组合。

A · drawio 默认扁平

默认的蓝框、细黑线、直角。干净，但就是你说的「质感一般」。放在这里作对照。

B · 柔和浅色（近两年 NeurIPS/ICLR 很常见）

圆角、浅色填充配同色系描边、灰色箭头。新模块用暖色容器，写出全名和缩写。输入输出放真实缩略图。

C · 立体特征图（CV 方向常见）

用立方体特征图表示分辨率逐级变化，加轻微阴影和渐变，模块有层次感。信息量大，但更容易显得挤。

D · 极简编辑风（偏 Nature / 期刊）

灰阶加一个强调色，细线、直角、大留白，层级靠字体区分。新模块用色块和左侧竖条标出。
